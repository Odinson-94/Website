What cable size for a 9.5kw shower?

A 9.5 kW shower does not have one universally correct cable size. Enter the actual voltage, route length, installation method, grouping, ambient conditions, protective device and Ze so the BS 7671 engine can check current capacity, voltage drop, Zs, disconnection time and CPC requirements together.

What cable size for a 7kw ev charger?

A 7 kW EV charger cable must be sized from its real circuit conditions, not power alone. The calculation needs route length, installation method, correction factors, protective device, earthing data and permitted voltage drop before it can return a reviewable cable and CPC result.

How do i size a cable by amps?

Start with design current Ib, choose the protective device In, apply the relevant correction factors to obtain required tabulated capacity It, then check the proposed cable for voltage drop, earth-fault-loop impedance, disconnection time and CPC adequacy.
