Direct answer

How does an EPC work in Scotland?

Scotland has its own EPC Register and Scottish Government guidance. An EPC can only be produced by an EPC assessor. The official guidance directs users to the Scottish register to find an assessor and to search for an existing certificate by postcode or report reference number.

Use the Scottish register

Do not use the England, Wales and Northern Ireland search route for a Scottish property.

Check current Scottish guidance

Scottish EPC requirements and methodology changes must be checked at the time of the assessment.

Keep modelling separate from lodgement

A scenario calculation can support review, but it is not a Scottish lodged certificate.

Frequently asked questions about energy performance certificate in Scotland.

Where is the Scottish EPC register?

Scottish Government guidance links to the Scottish EPC Register and its assessor search. Use that route for properties in Scotland.

Can I search for a Scottish EPC by postcode?

Yes. Scottish Government guidance states that an existing EPC can be checked on the Scottish register using the postcode. A report reference number can also be used.

Can the GOV.UK England and Wales register find a Scottish EPC?

No. GOV.UK points users to a different service for Scotland. Use the Scottish EPC Register.

Does Adelphos issue an official EPC?

No. An official EPC must be produced and lodged through the applicable accredited-assessor process. Adelphos can calculate and compare supported scenarios, but its calculation output is not a lodged certificate.

Calculation and certification responsibility

The user is responsible for verifying every input, assumption, method, result and its suitability, and for obtaining competent-person review. Adelphos accepts no responsibility for decisions made using a calculation. Adelphos scenario output is not an official EPC or an equipment recommendation.
