Direct answer

How does a new build EPC relate to SAP?

For dwellings, the government Standard Assessment Procedure is used to estimate energy performance and supports new-home compliance and EPC production. The applicable version and transitional rules depend on jurisdiction and project dates, while the official certificate still requires the approved software and accredited-assessor process.

Design calculation

The model records the proposed dwelling fabric, systems and other controlled inputs for compliance review.

As-built update

Changes made during construction must be reflected in the final assessment evidence.

Certificate and lodgement

A calculation report is not itself a lodged EPC. The accredited production route remains separate.

Frequently asked questions about new build EPC.

Is a SAP calculation the same as an EPC?

No. SAP is a dwelling energy-performance calculation methodology. An official EPC is produced and lodged through the applicable accredited process using approved software and verified project information.

Which SAP version applies to my project?

Check current government methodology notices and transitional provisions for the project jurisdiction and dates. Do not select a version from a generic web article alone.

Can Adelphos produce a SAP calculation?

Adelphos can run supported SAP scenarios using controlled project inputs and return a calculation for professional review. Project suitability, regulatory approval, EPC production and certificate lodgement remain with the responsible qualified process.

Does Adelphos issue an official EPC?

No. An official EPC must be produced and lodged through the applicable accredited-assessor process. Adelphos can calculate and compare supported scenarios, but its calculation output is not a lodged certificate.

Calculation and certification responsibility

The user is responsible for verifying every input, assumption, method, result and its suitability, and for obtaining competent-person review. Adelphos accepts no responsibility for decisions made using a calculation. Adelphos scenario output is not an official EPC or an equipment recommendation.
