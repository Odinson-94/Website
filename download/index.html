Getting started

Install Adelphos.

The desktop app and the AutoCAD plugin come as one package. Unpack it, run the installer, and you are working. There is nothing to configure and no licence key to enter.

Download

One package, both parts.

Adelphos-Setup.zip · 195 MB · Windows 10 and 11. Installs the desktop app and the AutoCAD plugin together.

Download Adelphos-Setup.zipStart download →
Three steps

Installing.

Both parts install to per-user locations, so you do not need administrator rights.

  1. Unzip it first. Right-click the file and choose Extract All. Running the installer from inside the zip copies nothing, and Windows will not tell you why.
  2. Run INSTALL.bat from the extracted Adelphos-Setup folder. It installs both parts and opens Adelphos when it is done.
  3. Restart AutoCAD if it was already open. The Adelphos panel loads on startup from then on.

Windows will warn you before it runs. This build is not code-signed yet, so you will see “Windows protected your PC”. Click More info, then Run anyway. If your browser blocks the download instead, choose Keep.

First run

Signing in and what to try.

Use the email address your account was set up with. Your credits are already on the account, so you can start straight away.

There are no commands to learn. Ask for what you want, attach a drawing when it asks, and Adelphos takes you through the rest.

  • Build me a SAP calculation — then attach the drawing when prompted
  • Build me a cable calculation from these drawings — attach a circuit schedule or drawing
  • Build me a stage 4 specification — attach your drawings
  • Give me a BMS points list
  • Summarise my emails and let's go through them

Two things are on display but not live yet. The thermal modeller and the lighting calculations are visible so you can see where this is heading. Everything else is working.

Support

Updates and problems.

Adelphos loads its interface from our servers, so improvements appear the next time you open it.

Do I need to reinstall when Adelphos is updated?

No. The interface comes from our servers, so improvements appear the next time you open the app or the AutoCAD panel. You only need to reinstall when we tell you there is a new version of the plugin.

Why does Windows say it protected my PC?

The build is not code-signed yet. Click More info, then Run anyway. If your browser blocks the download, choose Keep.

Do I need administrator rights?

No. Both the desktop app and the AutoCAD plugin install into your own user profile.

The AutoCAD panel has not appeared.

Restart AutoCAD. The plugin loads on startup once installed. If it still does not appear, tell us and we will look at it.
