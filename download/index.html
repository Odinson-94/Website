Install Adelphos

The desktop app and the AutoCAD plugin, in one package.

Everything installs in one go. Unpack the download, run the installer, and you are working. There is nothing to configure and no licence key to enter.

Download Adelphos

Adelphos-Setup.zip · ~195 MB · Windows 10 / 11

Installing

  1. Unzip the download. Right-click the file and choose Extract All. Do not run the installer from inside the zip, or Windows will copy nothing.
  2. Run INSTALL.bat from the extracted Adelphos-Setup folder. It installs both parts and opens Adelphos when it finishes.
  3. Restart AutoCAD if it was open. The Adelphos panel loads on startup from then on.

Windows will warn you before it runs. This build is not code-signed yet, so SmartScreen shows “Windows protected your PC”. Click More info, then Run anyway. If your browser blocks the download instead, choose Keep.

Where things go

ComponentInstalled to
Adelphos desktop app %LOCALAPPDATA%\AdelphosChat\current
AutoCAD plugin %APPDATA%\Autodesk\ApplicationPlugins\MEPBridge.AutoCAD.bundle

Both are per-user locations, so no administrator rights are needed.

Signing in

Use the email address your account was set up with. Your credits are already on the account, so you can start straight away.

Worth trying first

You do not need to learn any commands. Ask for what you want, attach a drawing when it asks, and it will guide you through the rest.

  • Build me a SAP calculation — then attach the drawing when prompted
  • Build me a cable calculation from these drawings — attach a circuit schedule or drawing
  • Build me a stage 4 specification — attach your drawings
  • Give me a BMS points list
  • Summarise my emails and let's go through them

Two things are on display but not live yet: the thermal modeller and the lighting calculations. They are visible so you can see where this is heading. Everything else is working.

Updates

The app loads its interface from our servers, so improvements appear the next time you open it. You only need to reinstall if we tell you a new version of the plugin is out.
