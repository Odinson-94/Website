Getting started

Install Adelphos

The desktop app and the AutoCAD plugin come as one package. Unpack it, run the installer, and you are working. There is nothing to configure and no licence key to enter.

Download Adelphos

Adelphos-Setup.zip · 195 MB · Windows 10 and 11

Installing

  1. Unzip it first. Right-click the file and choose Extract All. Running the installer from inside the zip copies nothing and Windows will not tell you why.
  2. Run INSTALL.bat from the extracted Adelphos-Setup folder. It installs both parts and opens Adelphos when it is done.
  3. Restart AutoCAD if it was already open. The Adelphos panel loads on startup from then on.

Windows will warn you before it runs. This build is not code-signed yet, so you will see “Windows protected your PC”. Click More info, then Run anyway. If your browser blocks the download instead, choose Keep.

Where it installs

ComponentLocation
Adelphos desktop app%LOCALAPPDATA%\AdelphosChat\current
AutoCAD plugin%APPDATA%\Autodesk\ApplicationPlugins\MEPBridge.AutoCAD.bundle

Both are per-user locations, so you do not need administrator rights.

Signing in

Use the email address your account was set up with. Your credits are already on the account, so you can start straight away.

Worth trying first

There are no commands to learn. Ask for what you want, attach a drawing when it asks, and it will take you through the rest.

  • Build me a SAP calculationthen attach the drawing when prompted
  • Build me a cable calculation from these drawingsattach a circuit schedule or drawing
  • Build me a stage 4 specificationattach your drawings
  • Give me a BMS points list
  • Summarise my emails and let's go through them

Two things are on display but not live yet. The thermal modeller and the lighting calculations are visible so you can see where this is heading. Everything else is working.

Updates

Adelphos loads its interface from our servers, so improvements appear the next time you open it. You only need to reinstall when we tell you there is a new version of the plugin.

If something does not work

Tell us what you were doing and what you saw, and we will fix it. Email jordan.jones@adelphos.ai.
