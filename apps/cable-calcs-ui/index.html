Cable calculation workflow

How to complete cable calcs and cable sizing checks.

A cable calculation starts with the real circuit duty and installation conditions. The proposed size is then checked for current capacity, voltage drop and fault protection before a competent person accepts it.

1. Establish the cable design current

Confirm the connected load, diversity, power factor, phases and supply voltage. Record the protective device and any starting-current or harmonic considerations supported by the design.

2. Define the cable route and installation method

Record route length, conductor material, insulation, ambient conditions, grouping, thermal insulation and the applicable reference installation method. These conditions affect the required tabulated capacity.

3. Check cable size and voltage drop

Compare the design current with the corrected current-carrying capacity, then calculate voltage drop over the declared route. Review the result within the complete installation rather than as an isolated number.

4. Check earth fault and CPC performance

Use the external loop impedance, conductor resistance, protective device and CPC information to review earth-fault-loop impedance, disconnection time and adiabatic performance against the applicable BS 7671 requirements.
